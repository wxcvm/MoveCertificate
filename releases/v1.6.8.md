MoveCertificate v1.6.8（versionCode 34）正式版，仅包含证书模块和 WebUI。

### 挂载与证书管理

- 兼容、内置两种模式均先检查证书内容，已正确生效时直接通过，减少重复校验及挂载脚本调用。
- init 验证成功后，子命名空间缺少证书或内容不符时使用已验证的系统证书库修复；无法进入命名空间仍明确失败。内置模式配置保持不变。
- 校验代码和预期 SHA-256 清单直接传入目标命名空间，避免目标视图隐藏模块目录时误报；相同活动 APEX 目录别名只校验一次。
- 记录进程真实名称、PID、命名空间、具体缺失/不符文件；启动器重启有限重试，允许启动后重试早期挂载失败。
- 每次启动从当前原生库重建，保留原生 CA 字节，按 DER 指纹去重并处理同 hash 冲突；准备失败不发布残缺证书集。
- WebUI 可逐张选择用户证书是否迁移，选择跨升级保留，完整名称可换行显示。取消迁移保留用户输入，重启生效；AdGuard 中间证书默认关闭、根证书默认开启，已有显式选择优先。
- 修复 Android mksh 锁描述符传递及 WebUI 保存错误反馈。

### 构建与发布

- 安装包采用明确的运行时文件和文档图片清单，排除本地诊断、额外脚本及测试证书。
- WebUI 使用固定混淆种子，并按最终脚本字节生成内容哈希，避免缓存旧脚本。
- Release 绑定对应标签提交，提供 SHA-256 校验文件，不覆盖已发布附件。

### 验证范围

- Linux CI：WebUI、证书运行时、命名空间、启动状态、打包隔离、真实 flock、Shell 语法、TypeScript 和完整构建。
- PGKM10 / Android 17 / KernelSU：Android 原生 Shell 回归通过；v1.6.8 校验器对 init、32/64 位 Zygote、WebView、Quetta 启动器五个活动命名空间的只读内容检查通过。
- 在独立且递归私有的挂载命名空间中执行了两种模式的真实 bind 修复，确认内容正确、原始输入保留、无效源不挂载。
- 当前手机已安装 v1.6.7 并以兼容模式启动为 ready。以上测试不等于 v1.6.8 完整开机验收；内置模式与元模块的完整开机路径仍待重启验证，其余设备/ROM 未做实机验收。

### 安装

直接下载附件 **MoveCertificate-v1.6.8.zip**，在 Magisk / KernelSU / APatch 中选择安装并完整重启。Release ZIP 可直接刷入，无需解压；不要将 GitHub 自动生成的源码 ZIP 当作模块包。

保留现有模式及证书选择。Android 14+ 使用内置模式时，需要支持活动 APEX 挂载的提供者。

若仍出现验证失败，可获取只读诊断：

```sh
adb shell su -c 'sh /data/adb/modules/MoveCertificate/sh/diagnose.sh'
adb pull /data/local/tmp/MoveCertificate.log
```

校验下载文件：将 ZIP 与 `.sha256` 附件放在同一目录，运行 `sha256sum -c MoveCertificate-v1.6.8.zip.sha256`；Windows 可用 `Get-FileHash .\MoveCertificate-v1.6.8.zip -Algorithm SHA256` 对比摘要。
